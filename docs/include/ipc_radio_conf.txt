When building this |sample_or_app| with :ref:`Sysbuild <nrf:configuration_system_overview_sysbuild>` for an SoC that has a network core, the :doc:`IPC radio <nrf:applications/ipc_radio/README>` is automatically applied to the build.
The IPC radio is one of the :doc:`Companion components <nrf:app_dev/companion_components>` in the |NCS| and allows you to use the radio peripheral from another core in a multicore device.
If needed, you can modify the IPC radio configuration in the :file:`prj.conf` source file in the |sample_or_app|'s |ipc_radio_dir| directory.
